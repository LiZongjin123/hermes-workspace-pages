Agent — 个人 Google Tasks 助手

Agent 是个人自用的 Google Workspace 集成，使用 gws CLI 将 Google Tasks 接入本人运行的 Hermes 助手。这不是 Google 官方产品，也不提供公众注册服务。

功能与授权

在账号持有人指示下读取任务列表，以及创建、修改、整理或删除任务。Google Tasks 的任务权限覆盖这些操作；授权本身不意味着助手会自行执行它们。当前此集成仅请求 Tasks 和基本登录身份权限，不因发布此网页而额外申请 Gmail 或 Drive 等权限。

运行方式

gws 与 Hermes 在账号持有人控制的服务器运行。此 GitHub Pages 网站仅提供应用说明和隐私政策，不接收 OAuth 回调、不处理任务内容、不保存凭证。

隐私政策 / Privacy Policy · 联系维护者

仅供个人使用。此网站不包含 Google 登录功能。
