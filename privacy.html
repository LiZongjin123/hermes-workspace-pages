Agent 隐私政策

本政策适用于个人自用的 Agent Google Tasks 集成（gws CLI 与 Hermes 助手）。

访问的数据和用途

授权后，该集成可访问 Google Tasks 的任务列表及任务，包括标题、备注、状态、截止日期等，以及基本登录身份信息。数据仅用于账号持有人要求的任务查询、创建、更新、整理和删除，不用于广告、出售或建立跨用户画像。

处理、存储与第三方服务

gws 与 Hermes 在账号持有人控制的服务器上处理请求。OAuth 凭证由 gws 加密保存于服务器；凭证、任务内容和服务器配置不上传到此公开网站或其 GitHub 仓库。

Hermes 对话历史、工具输出及运行日志可能保留任务相关内容。执行助手请求时，相关内容也可能发送给 Hermes 当前配置的模型服务及所使用的消息平台；它们依各自的隐私和数据保留条款处理内容。本政策不声称这些第三方数据永不保留或永不用于训练。此集成不会故意向模型或消息平台披露 OAuth 凭证。

维护者不将通过 Google API 获取的数据用于训练通用人工智能模型。Agent 对 Google API 数据的使用和转移将遵守 Google API Services User Data Policy，包括适用的 Limited Use 要求。

公开网站

本网站无登录表单、无应用分析脚本，不接收 Google 任务数据。GitHub Pages 的托管服务可能处理 IP 地址等访问元数据，具体见 GitHub 隐私声明。

撤销授权和删除

账号持有人可在 Google 账号第三方连接设置撤销 Agent 的访问，并使用 gws auth logout 清除本地授权。删除凭证不自动删除 Google Tasks 中的任务，也不自动删除 Hermes 历史、日志或第三方保留数据；这些需分别通过各服务的控制方式清理。本集成不设独立统一的数据自动删除期限。

联系

通过 项目联系渠道联系维护者。GitHub Issues 是公开的，请勿提交账号密码、令牌或私人任务内容。
